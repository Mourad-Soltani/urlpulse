## Product Overview
URLPulse is a minimal bulk URL health checker. Ideal for developers, SEO specialists, or ops teams who need to quickly validate a list of links.

## Key Selling Points
- Zero setup beyond Python + pip
- Concurrent checks (fast)
- Clear healthy/unhealthy summary
- API + simple UI
- Fully open source (MIT)

## Potential Pricing
- Free tier: 50 checks/day
- Pro: $9/mo unlimited + email alerts (future)
